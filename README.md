# 工贸 ERP · 独立界面演示版

这是可单独分享的静态演示，不是现有 ERP 的部署包。

## 本地查看

直接用浏览器打开 `index.html`，或使用任意静态文件服务器打开本目录。页面无需安装依赖、登录或连接数据库。

## 演示范围

- 工作台、进销存、生产管理、财务管理、经营报表、审批与流程、系统集成、组织与账号。
- 左侧可展开的模块导航、页面切换、样例搜索和只读详情。
- 公司、人员、单据、金额均为手写虚构样例；页面不会请求 ERP API，也不会保存数据。
- 不提供新增、编辑、审批、过账等真实业务动作。

## 将来发布到 GitHub Pages

建议新建一个**独立仓库**，只上传本目录中的 `index.html`、`styles.css`、`app.js` 和本说明文件，放在仓库根目录，然后在仓库设置中启用 GitHub Pages。不要把整个 ERP 项目、`.env`、数据库文件或真实业务数据上传进去。

GitHub Pages 默认面向公网；仅知道链接并不等于只有指定的人能访问。若要限制访问者，不要把该页面当成私密演示。
