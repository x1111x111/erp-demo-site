# 工贸 ERP · 独立界面演示版

这是可单独分享的静态演示，不是现有 ERP 的部署包。

## 本地查看

直接用浏览器打开 `index.html`，点击“进入演示工作台”即可浏览。`app.html` 是工作台页面，也可以直接打开。页面无需安装依赖或连接数据库。

## 演示范围

- 工作台、进销存、生产管理、财务管理、经营报表、审批与流程、系统集成、组织与账号。
- 左侧可展开的模块导航、页面切换、样例搜索和只读详情。
- 公司、人员、单据、金额均为手写虚构样例；页面不会请求 ERP API，也不会保存数据。
- 不提供新增、编辑、审批、过账等真实业务动作。
- 首页是“演示访客”入口，不是身份验证；没有账号、密码，也不收集凭据。

## GitHub Pages 发布与安全边界

本目录的 `index.html`、`app.html`、`styles.css`、`app.js` 和本说明文件上传到独立仓库根目录后，可通过 GitHub Pages 展示。不要上传整个 ERP 项目、`.env`、数据库文件或真实业务数据。

当前公开演示地址是 <https://x1111x111.github.io/erp-demo-site/>。GitHub Pages 上的此演示面向公网，任何人都可直接访问 `app.html`，首页不能限制访问者。若需要真正的登录、用户权限和私密数据，请把真实 ERP 部署在有后端认证与访问控制的环境中，不要用这个静态演示版代替。
